= 非プライマリ管理ノードを使用してStorageGRIDプライマリ管理ノードを交換する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
プライマリ管理ノードをリカバリするには、まず物理または仮想ハードウェアの交換が必要です。

* 障害が発生したプライマリ管理ノードは、同じプラットフォーム上で稼働しているプライマリ管理ノードに置き換えることができます。
* VMware または Linux ホスト上で実行されているプライマリ管理ノードを、StorageGRID サービスアプライアンスでホストされているプライマリ管理ノードに置き換えることができます。
* VMwareホスト上で稼働しているプライマリ管理ノードを、SG1000またはSG100サービスアプライアンスに置き換えることができます。


ノードに対して選択した交換用プラットフォームに一致する手順 を使用します。（すべてのノードタイプに適した）ノード交換手順 を完了すると、プライマリ管理ノードのリカバリに関する次のステップが手順 から表示されます。
