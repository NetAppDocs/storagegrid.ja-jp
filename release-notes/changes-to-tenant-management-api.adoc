= StorageGRID のテナント管理 API の変更
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 12.1では、テナント管理APIのバージョン4を使用しています。バージョン4ではバージョン3は非推奨となりますが、バージョン1、2、3は引き続きサポートされます。


NOTE: 非推奨バージョンのテナント管理 API は StorageGRID で引き続き使用できます。ただし、これらのバージョンの API のサポートは、今後の StorageGRID のリリースで削除される予定です。StorageGRID 12.0 以降にアップグレードした後、 `PUT /grid/config/management` API を使用して非推奨の API を無効化できます。

詳細については、を参照してくださいlink:../tenant/understanding-tenant-management-api.html["テナント管理 API について理解する"]。
