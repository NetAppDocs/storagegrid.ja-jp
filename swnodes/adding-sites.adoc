= StorageGRID でサイトを追加する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID をインストールするときに、サイトを少なくとも 1 つ作成する必要があります。StorageGRID システムの信頼性を高め、ストレージ容量を増やすために、追加のサイトを作成することができます。

.手順
. サイトページで、*サイト名*を入力してください。
. サイトを追加するには、最後のサイトエントリの横にあるプラス記号を選択し、新しい *Site name* テキストボックスに名前を入力します。
+
グリッドトポロジに必要な数のサイトを追加します。サイトは最大 16 個まで追加できます。

+
image:3_gmi_installer_sites_page.gif["この図には説明が付随しています。"]

. 「 * 次へ * 」を選択します。
